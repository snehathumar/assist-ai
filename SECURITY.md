# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Please report any security vulnerabilities by opening an issue on this repository or contacting the maintainers directly.
All payloads are processed ephemerally, and no PII or PHI is stored.
